# Kodacam website

Static support and privacy pages for Kodacam, developed by Alexei Markel.

Render setup: New → Static Site, choose this repository, branch main. Leave the root directory blank, set build command to `mkdir -p public && cp index.html support.html privacy.html style.css kodacam.svg public/` and publish directory to `public`. No paid web server or custom domain is required.

App Store URLs after deployment: `/support.html` and `/privacy.html`.

Public contact: alexeivmarkel@gmail.com.
